# ANSARI'S 👕

A modern and responsive **clothing store website** built for **ANSARI'S**. The website provides a stylish online presence for showcasing clothing products and making it easy for customers to connect with the store.

## ✨ Features

* 📱 Fully responsive design
* 👕 Clothing/product showcase
* 🏪 About ANSARI'S section
* ⭐ Customer reviews & ratings
* 📞 Contact section
* 💬 Floating WhatsApp button
* 🎨 Modern navy-blue & sky-blue color theme
* ⚡ Smooth and user-friendly interface
* 🖼️ Attractive product image gallery

## 🛍️ Website Sections

1. **Home** – Introduction and brand heading
2. **About Us** – Short introduction about ANSARI'S
3. **Products** – Clothing collection and images
4. **Reviews** – Customer feedback and ratings
5. **Contact** – Store contact information
6. **WhatsApp** – Quick customer communication

## 🎨 Design

The website uses a modern color combination:

* **Primary:** Navy Blue
* **Secondary:** Sky Blue / Light Blue
* **Style:** Clean, modern and minimal

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ansaris.git
```

### 2. Open the project

Go to the project folder:

```bash
cd ansaris
```

### 3. Run the website

Simply open `index.html` in your browser.

For the best development experience, you can use **VS Code with Live Server**.
